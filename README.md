# AI_BOT

Telegram-бот на Node.js (CommonJS, Node 20+):

- обычный бот: текст, голосовые (расшифровка), фото (vision), память диалога, команды и кнопки;
- ассистент аккаунта: готовит черновики ответов на личные сообщения вашего Telegram-аккаунта, отправляет только с вашего подтверждения (режим `auto` ограничен, см. ниже);
- режим bot-to-bot: диалог с другим ботом с лимитом ходов;
- userbot: простые команды (`.ping`, `.say`, …) от имени вашего аккаунта, только для вас.

ИИ работает через [OpenRouter](https://openrouter.ai).

## AI-лаборатория

Открой `/lab` или кнопку **🔬 AI-лаборатория** в личном диалоге с ботом:

- **Идеи программ:** три идеи → выбор → уточнение/план/разбор слабых сторон → сохранение проекта → создание инструмента.
- **AI-эксперименты:** общая задача и данные → два промпта → предварительный просмотр → «Запустить: 2 генерации» → реальные ответы, время и доступный usage. Скрытых повторов нет; неудачный вариант можно повторить отдельно после подтверждения.
- **Обучение:** JavaScript/Python, два уровня, по три коротких занятия, задания на чтение кода, подсказки, проверка попыток и сохранение прогресса. Свой код разбирает AI без исполнения.
- **Мини-инструменты:** спецификация → генерация одного HTML/Node.js-файла → проверка формата → скачивание с инструкцией и примерами. Бот код не запускает.

Данные лаборатории отделены от памяти чата. Доступны просмотр, экспорт и подтверждаемое удаление. `/reset` сохраняет прежний смысл: очищает обычную память чата. Возврат к беседе — «← Обычный чат».

Лаборатория включена по умолчанию; `AI_LAB_ENABLED=false` полностью отключает её обработчики и пункт меню. Остальные настройки `AI_LAB_*` описаны в `.env.example`. Ключ OpenRouter остаётся прежним, отдельный OpenAI API-ключ не нужен.

Подробные сценарии, лимиты, хранение и границы проверки: [docs/AI_LAB.md](docs/AI_LAB.md). Локальные проверки и ограничения поставки: [отчёт](audit-reports/ai-lab-20261029/REPORT.md).

## Быстрый старт

```bash
cp .env.example .env      # заполните BOT_TOKEN и OPENROUTER_API_KEY
npm ci
npm start
```

Если оставить обязательные значения пустыми или заглушками, бот не запустится и скажет, что именно не так.
`.env` в git не попадает; не отправляйте его и его содержимое никуда.

## Безопасность

- **Сессия Telegram (`TELEGRAM_STRING_SESSION`) — это полный доступ к аккаунту.** Хранится только в `.env`. Файлы `*.session` и `memory.json*` закрыты в `.gitignore`.
- Если сессия или `.env` когда-либо попали в публичное место: завершите сессию (Telegram → Настройки → Устройства), создайте новую через `npm run telegram:session`, перевыпустите `BOT_TOKEN` у @BotFather и ключ OpenRouter.
- Одну сессию нельзя использовать в двух процессах одновременно (например `npm start` с ассистентом и `npm run userbot`): Telegram отзовёт её.
- По умолчанию бот отвечает всем, кто ему напишет, и тратит ваш ключ OpenRouter. Ограничьте круг через `BOT_ALLOWED_USER_IDS` (ID через запятую). Лимит запросов на пользователя (`RATE_LIMIT_MESSAGES` за `RATE_LIMIT_WINDOW_MS`) действует всегда, владелец не ограничен.
- В логи не попадают токены, ключи и тексты сообщений. Тексты можно включить для отладки: `LOG_MESSAGES=true` (это личные данные).
- Публичный `GET /health` отдаёт только `ok` и uptime. Подробности — `GET /health/details`, он включается только при заданном `HEALTH_TOKEN` (заголовок `x-health-token` или `Authorization: Bearer …`).
- `memory.json` содержит переписку. Не публикуйте его и не кладите в репозиторий.

## Настройки

Полный список с комментариями — в [`.env.example`](.env.example). Главное:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN`, `OPENROUTER_API_KEY` | обязательные |
| `OPENROUTER_MODEL`, `OPENROUTER_VISION_MODEL`, `OPENROUTER_STT_MODEL`, `OPENROUTER_AUDIO_MODEL` | модели |
| `OPENROUTER_MAX_TOKENS` | предел длины генерации, по умолчанию 1500 |
| `BOT_ALLOWED_USER_IDS`, `BOT_OWNER_CHAT_ID` | кто может писать боту / кто владелец |
| `MAX_AUDIO_BYTES`, `MAX_IMAGE_BYTES` | лимиты файлов: число байт или `25MB`, `512KB`, `1.5GB` |
| `MAX_REPLY_PARTS` | сколько сообщений максимум в одном ответе (по умолчанию 6) |
| `PORT`, `HEALTH_TOKEN` | веб-сервер и подробный health |
| `LOG_LEVEL`, `LOG_MESSAGES` | уровень (`debug`, `info`, `warn`, `error`, `silent`); тексты сообщений в логах |
| `MEMORY_FILE` | где хранится память (по умолчанию `memory.json` рядом с проектом) |

Неверные числовые значения не отключают защиту молча: бот пишет предупреждение и берёт значение по умолчанию.

## Команды бота

Всем: `/start`, `/menu`, `/help`, `/voice`, `/status`, `/reset` (очистить память этого чата), `/lab` (если лаборатория включена). Те же действия доступны кнопками.
Длинные ответы ИИ приходят несколькими сообщениями (Telegram принимает до 4096 символов в одном).
Команды, адресованные другому боту (`/help@other_bot`), игнорируются.

Только владельцу (меню команд Telegram показывает их только в чате владельца):

| Команда | Что делает |
|---|---|
| `/account_help`, `/account_status`, `/account_config`, `/account_pending` | справка, состояние, настройки, список черновиков |
| `/account_send id`, `/account_drop id`, `/account_reply id текст`, `/account_redraft id` | действия над черновиком |
| `/account_message @username текст` | написать от имени аккаунта |
| `/account_mode approval` / `auto` / `dry-run`, `/account_private true` / `false` | режим и «только личные чаты» |
| `/account_allow`, `/account_unallow`, `/account_block`, `/account_unblock` | списки контактов |
| `/account_enable`, `/account_disable` | включить/выключить ассистента |
| `/bot_status`, `/bot_send текст` или `/bot_send @bot текст` | общение с другим ботом |

Режим, списки и `private-only`, изменённые командами, действуют **до перезапуска**; постоянные значения задаются в `.env`.

## Ассистент аккаунта

Нужны `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_STRING_SESSION` (`npm run telegram:session`) и `ACCOUNT_ASSISTANT_OWNER_CHAT_ID`.

- `approval` (по умолчанию): на каждое входящее приходит черновик с кнопками «Отправить / Редрафт / Отклонить / Заблокировать отправителя». Без вашего нажатия ничего не уходит.
- `dry-run`: то же, но отправить нельзя.
- `auto`: бот отвечает сам, только контактам из `ACCOUNT_ASSISTANT_ALLOW_CHATS`. Ответы со ссылками, деньгами, номерами карт, реквизитами и секретами в любом случае требуют вашего подтверждения. Если список разрешённых пуст, `auto` работает как `approval` (снять защиту можно только явно: `ACCOUNT_ASSISTANT_AUTO_ALLOW_ANY=true`, это небезопасно).
- Контакты сопоставляются по числовому ID и username, не по имени. Сообщения от одного контакта, пришедшие чаще `ACCOUNT_ASSISTANT_MIN_INTERVAL_MS`, объединяются в один черновик.

## Userbot (`npm run userbot`)

Команды: `.help`, `.ping`, `.say текст`, `.echo текст`, `.whoami`, `.status`, `.chatid`, `.time`.
Принимаются **только от самого аккаунта** (ваши исходящие сообщения с любого устройства) и от пользователей из `USERBOT_ALLOWED_USER_IDS`. Остальным userbot не отвечает.

## Память

Диалоги и профиль собеседника хранятся в `memory.json`: запись отложенная и атомарная, раз в несколько минут делается копия `memory.json.bak`. Если файл повреждён, он переименовывается в `memory.json.corrupt-…`, а бот берёт копию. На хостингах с временной файловой системой данные не переживут перезапуск: укажите `MEMORY_FILE` на постоянный том.

## Разработка

```bash
npm run lint     # ESLint
npm test         # unit + интеграционные тесты, интернет не нужен
npm run check    # lint + test
```

Интеграционные тесты запускают настоящий бот против локальных фейков Telegram Bot API и OpenRouter (`tests/helpers`). Для этого есть переменные `TELEGRAM_API_BASE_URL` и `OPENROUTER_BASE_URL` — ими же можно подключить свой сервер Bot API. CI (GitHub Actions) гоняет lint, тесты на Node 20/22/24 и `npm audit`.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| бот сразу завершается с «Некорректная конфигурация» | заполнены ли `BOT_TOKEN` и `OPENROUTER_API_KEY` в `.env` (не заглушки, не пусто) |
| «Web server could not start» | порт занят, смените `PORT` |
| бот молчит | `BOT_ALLOWED_USER_IDS`, лимит запросов (`RATE_LIMIT_*`), `LOG_LEVEL=debug` |
| `409 Conflict` в логах | тот же `BOT_TOKEN` опрашивает второй экземпляр |
| ассистент «не стартовал» | `TELEGRAM_*` и `ACCOUNT_ASSISTANT_OWNER_CHAT_ID`; `/account_status` покажет причину |
| голосовые не расшифровываются | `OPENROUTER_STT_MODEL`, баланс и ключ OpenRouter; подробности в логе |
