# Улучшения подготовки VPS

- `npm run package:vps`: повторяемая упаковка текущего кода с уникальным именем, SHA-256 и manifest; окончания строк нормализуются для Linux.
- `npm run check:vps -- --env FILE`: предпроверка без сетевых запросов и вывода значений ключей.
- Секреты веб-панели и webhook генерируются криптографически на сервере и не перезаписываются при повторном создании env.
- Системная служба запускается от `ai-bot`, применяет минимальные права, лимит перезапусков и отдельный каталог состояния.
- Установка использует lock от параллельных deployment, проверяет исходный пакет и отдельную остановку перед обновлением.
- Документированы SSH-туннель, webhook, публичная веб-панель, health, журналы, проверка стабильности, перенос данных и границы отката.
- Добавлены 7 содержательных регрессионных тестов упаковки и предпроверки; production-зависимости проверены отдельной чистой установкой.

Новые зависимости не добавлены; бизнес-логика, команды и интерфейс приложения сохранены.
