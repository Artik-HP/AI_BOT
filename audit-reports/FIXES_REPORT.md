# Отчёт об исправлениях

Дата: 2026-10-19. Ветка `claude/full-audit-ai-bot` (откат: тег `pre-audit-baseline`, `e2a47fe`).
Первичный аудит (заморожен, не редактировался): [`AUDIT_INITIAL_2026-10-19_02-03.md`](AUDIT_INITIAL_2026-10-19_02-03.md).

Правило, по которому ставился статус: **«ИСПРАВЛЕНО» — только если есть автоматический тест, который
падает на исходном коде и проходит на новом** (колонка «Контроль»), либо проверка инструментом
(`npm audit`, ESLint). Всё остальное помечено честно: «ДОКУМЕНТАЦИЯ», «ДЕЙСТВИЕ ВЛАДЕЛЬЦА», «ЧАСТИЧНО».

Условные обозначения контроля: **B** — тест падает на baseline (проверено запуском набора против
исходного кода), **T** — тест есть и проходит, **M** — мутация (намеренная поломка этого фикса) обнаружена
набором тестов (`evidence/after/mutation-check.js`), **L** — проверено линтером/инструментом.

## Дополнительные дефекты, найденные уже в ходе исправлений

| Что | Как найдено | Что сделано |
|---|---|---|
| `stopPolling({ cancel: true })` не останавливает опрос (цикл перезапускается в `finally`); из-за этого при shutdown бот ещё принимал сообщения | зависание тестового набора, затем эксперимент | `stopTelegramPolling`, регрессионный тест |
| Сообщение без `id` ошибочно считалось повтором (после добавления дедупликации) | ревью собственной правки | сообщения без `id` пропускаются; тест |
| `\b` не работает с кириллицей — правило «деньги/карта» в `findAutoSendRisk` не срабатывало | тест | Unicode-lookaround с флагом `u` |
| Teardown фейковых серверов в тестах ждал keep-alive ~6 с | профилирование | сокеты закрываются до `close()`; набор стал быстрее |
