# Первичная проверка подготовки VPS — 19.10.2026

Область: запрошенная заготовка размещения AI_BOT на VPS. Это проверка развёртывания и связанных контрактов приложения, а не полный повторный аудит всех функций из общего приложенного задания. Production, DNS и внешние аккаунты не изменялись.

## Исходное состояние

- Рабочий проект: вложенная папка `AI_BOT`, CommonJS, `index.js`, Node.js >=22.13, встроенный SQLite.
- Проверены `AGENTS.md`, конфигурация, запуск и остановка, Telegram polling/webhook, веб-панель, файловые пути, запись настроек, существующие Ubuntu-шаблоны, пакет зависимостей и старые отчёты в `docs/`.
- `npm run verify`: PASS, 167/167 тестов; синтаксис PASS; ESLint: 0 ошибок, 1 прежнее предупреждение (`src/commandSystem/userbot.js`, неиспользуемый `ctx`).
- `docs/command-system-report.md` ранее явно оставлял VPS/webhook production непроверенными. Эти пункты не считаются закрытыми историческими результатами.
- В рабочем дереве много пользовательских изменений. До правок сохранены копии шести затрагиваемых файлов, SHA-256 и Git-статус в `.local/vps-prep-2026-10-19_04-30/`. Секреты и пользовательские данные в снимок не копировались.
- WSL не установлен, Docker daemon недоступен. Есть Git Bash для проверки shell-синтаксиса; настоящий systemd и Caddy здесь пока не запускались.

VPS004 подтверждён сопоставлением шаблона с `mountWeb`, `access` и `envSettings`; VPS005 — содержимым `deploy/ubuntu`.
