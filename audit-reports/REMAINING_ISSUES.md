## 2. Технические остатки

| № | Проблема | Серьёзность | Что известно | Рекомендация |
|---|---|---|---|---|
| R1 | Пакет `telegram` (gramjs) помечен апстримом как устаревший | Medium (будущее) | Работает на `2.26.22`, форма API сверена с исходниками; миграцию на поддерживаемый форк без живого Telegram проверить нельзя | Запланировать миграцию отдельной задачей с настоящим тестовым аккаунтом. Изоляция уже есть: gramjs загружается лениво и создаётся через `createClient` |
| R2 | Ни `api.telegram.org`, ни `openrouter.ai` недоступны из среды аудита | Medium (непроверенное) | Всё проверено против локальных фейков (HTTP-эмуляторы Telegram Bot API и OpenRouter, стаб gramjs). Реальные лимиты Telegram, список моделей, формат STT-эндпоинта, поведение `setMyCommands` по областям — **не проверялись** | Один ручной прогон «дымовых» сценариев на тестовом боте после деплоя (чеклист в `FINAL_READINESS.md`) |
| R3 | Модель STT по умолчанию (`OPENROUTER_AUDIO_MODEL`, `thedrummer/cydonia-24b-v4.1`), вероятно, не принимает аудио | Medium | Остановка каскада на фатальных ошибках сделана; пригодность самой модели проверить нельзя | Указать в `.env` модель, которая действительно умеет аудио, и проверить голосовым сообщением |
| R4 | `node-telegram-bot-api@0.67` тянет устаревший `request`; подменён через `overrides` на `@cypress/request` | Low | Набор тестов (155) зелёный на фейках, `npm audit` — 0 | Следить за Dependabot; при желании — миграция на 2.x (полный переход на ESM, отдельная задача). Мажорные обновления `eslint` 10 и `dotenv` 18 тоже не применялись — Dependabot предложит их отдельными PR |
| R5 | Настройки ассистента, изменённые командами `/account_*`, и неподтверждённые черновики не переживают перезапуск | Low (сознательно) | Режим `auto` не должен «залипать» после перезапуска; об этом предупреждают ответы команд, README и ARCHITECTURE | Если нужна персистентность — отдельная задача с явным подтверждением режима `auto` после рестарта |
| R6 | Память диалогов (`memory.json`) хранится открытым текстом | Low–Medium | Файл вне репозитория, права — как у остальных файлов процесса. Тексты сообщений в лог не пишутся | При хостинге на общем диске — ограничить права / зашифровать том; рассмотреть срок хранения |
| R7 | Эвристика `findAutoSendRisk` (регулярные выражения) — не гарантия | Low | Ловит деньги, ссылки, секреты, реквизиты; обычная речь проходит. Для режима `auto` дополнительно нужен allow-list | Держать `auto` только для доверенных контактов; по умолчанию — режим подтверждения |
| R8 | Состояние лимитов, очередей и дедупликации живёт в памяти одного процесса | Low | Один экземпляр бота на токен — это и так ограничение long polling (второй получит `409 Conflict`; теперь лог это подсказывает) | Для горизонтального масштабирования нужен webhook и общее хранилище — вне объёма задачи |
| R9 | Devcontainer не собирался, CI-матрица Node 24 не запускалась | Low | Локально проверены Node 20 и 22 | Проверится первым прогоном CI / открытием в devcontainer |
| R10 | `npm run telegram:session` (интерактивный вход) не запускался | Low | Нужен настоящий номер телефона и код из Telegram | Проверить вручную при создании новой сессии (п. 1 выше) |
