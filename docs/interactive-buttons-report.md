# Интерактивные вопросы AI — отчёт от 14 октября 2026

## 1. Что реализовано

Система встроена в основной Telegram-бот, обработчики текста, голоса и фотографий. Модель формирует вопрос и динамические варианты; одиночный выбор передаёт полное `value`, множественный выбор сохраняет отметки и отправляет их после подтверждения. Есть ручной ввод, страницы длинных списков, состояние обработки и явный повтор при ошибке.

Единая JSON-схема проходит проверку типов, обязательных полей, уникальности идентификаторов, размеров и дополнительных полей. Служебный JSON не выводится как вопрос; незавершённый поток не создаёт кнопки. Код и произвольные инструменты модели не выполняются. Учитываются JSON с ограждением и коротким вступлением; обычные примеры кода остаются текстом.

Вопрос связан с конкретным сообщением, чатом, автором и моделью. Состояние и callback ID сохраняются на диске. Отправка защищена от повторных нажатий, пользовательская история записывается один раз. При повторе доставки используется сохранённый ответ AI, подтверждённые части сообщения не отправляются заново. После перезапуска отправка автоматически не запускается.

## 3. Совместимость

В проекте подключён OpenRouter. Реально проверены модели `cognitivecomputations/dolphin-mistral-24b-venice-edition` и `openai/gpt-4o-mini` с ключом из `.env`. Dolphin использует JSON Object; GPT-4o mini — JSON Schema, также проверены Tool Calling и резервный формат по инструкции. Проверены непотоковые и потоковые ответы, включая поток аргументов инструментов и настоящее изображение на vision-модели.

Возможности определяются для каждой модели отдельно, с кэшем каталога на час. Отказ в поддержке параметров приводит к резервному запросу без них. Ошибочный вопрос получает одну попытку исправления; если структурированный формат получить не удаётся, остаётся текстовый интерфейс. Для выбранного ответа сохраняется исходная модель вопроса.

- Реальные OpenRouter-проверки: **12 успешно, 0 ошибок в финальном прогоне**. Для каждой из двух основных моделей проверены размещение (single), функции (multiple), открытый вопрос; дополнительно проверены пять вариантов транспорта и изображение. Локальные тесты используют реальные сервисы и файловую память, но заменяют внешние транспорты для воспроизводимого моделирования ошибок. Финальный OpenRouter-прогон делает настоящие API-запросы без заглушек. Его результаты сохранены в `docs/interactive-live-results.json`; он не подтверждает доставку и нажатия Telegram.

Регрессионные проверки подтвердили обычный текст, меню и команды, контракт bot-to-bot (упоминание и ответ исходному сообщению), формат черновиков аккаунт-ассистента, обработчики голоса/фото и разбиение длинных сообщений с emoji. Реальные STT и отправка сообщений аккаунт-ассистентом не проверялись в этой задаче.

Контрольные суммы `.env`, `memory.json`, `memory.json.bak` и `userbot.session` совпали с состоянием перед задачей. Тестовая память находится в отдельных временных каталогах. Ранее существовавшие изменения сохранены. Коммит, push и деплой не выполнялись.

## 6. Известные ограничения

Это нативный интерфейс Telegram: его цвета, шрифты, мобильная компоновка и управление клавиатурой определяются клиентом Telegram. Их визуальная проверка на компьютере и телефоне ещё не выполнена. Bot API отправляет сообщения от бота, поэтому в Telegram выбор показан подтверждением «Твой ответ»; в AI-истории он сохраняется с ролью `user`.

При обрыве сети после принятия сообщения Telegram, но до получения ответа сервером, API не предоставляет ключ идемпотентности для `sendMessage`. Подтверждённые отправки не дублируются; абсолютную гарантию для этого неоднозначного сетевого случая дать нельзя.

Число вариантов динамическое, с пределом 100 для защиты ресурсов; страницы содержат шесть вариантов. Максимальные размеры задаются схемой. Модель может выбрать текстовый ответ или ошибиться в содержании; система проверяет структуру и повторённые варианты, но не гарантирует смысловую точность любой генерации. Прямые подключения других провайдеров, отдельный веб-чат и распределённое хранилище в исходной архитектуре отсутствуют.
