# Полный реестр команд

Источник: src/commandSystem/registry.js. Обновление: npm run commands:catalog.

Всего 80 записей: 70 видимых команд Telegram, 51 веб-команда, 8 команд отдельного userbot, 2 служебные записи (bot_chat, select). Права владельца проверяются при каждом выполнении.

Схема входа каждой команды — объект с единственным строковым полем args, максимум 16000 символов, без управляющих символов. Команда дополнительно проверяет собственный синтаксис, диапазоны и состояние сценария.
