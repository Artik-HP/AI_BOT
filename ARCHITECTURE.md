# ARCHITECTURE.md

## Обзор архитектуры

Проект `AI_BOT` построен на Node.js с CommonJS-модулями и состоит из двух основных режимов работы:

- `npm start` — обычный Telegram-бот, работающий через `index.js` и `src/bot.js`.
- `npm run userbot` — отдельный Telegram userbot, работающий через `scripts/userbot.js`.

Проект разделён на модули старта, обработчиков, сервисов и конфигурации.

## Основные компоненты

### `index.js`

Главный вход в приложение для обычного бота. Он подключает переменные окружения из `.env` и вызывает `src/bot.js`.

### `src/bot.js`

Основная логика запуска бота:
- загрузка и валидация конфигурации через `src/config.js`;
- создание Telegram-бота через сервис Telegram;
- регистрация команд и меню в `src/commands.js`;
- регистрация обработчиков голосовых, фото и текстовых сообщений в `src/handlers/`;
- запуск Express-сервера для проверки состояния (`/` и `/health`).

### `scripts/userbot.js`

Отдельный режим, в котором бот работает как пользовательский аккаунт Telegram.
Он использует пакет `telegram` и подключается через `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_STRING_SESSION`.
Этот режим полезен для аккаунт-ассистента или задач, когда нужно действовать от имени пользователя.

### `scripts/create-telegram-session.js`

Утилита для создания `TELEGRAM_STRING_SESSION` — сессии пользователя Telegram.

## Сервисы

### `src/services/telegram.js`

Содержит создание бота Telegram и управление состоянием bot-to-bot.

### `src/services/openrouter.js`

Возвращает конфигурацию моделей и STT, которая используется для голоса и AI-интеграций.

### `src/services/memory.js`

Отвечает за хранение сообщений, историю и долговременную память по чатам.

### `src/services/accountAssistant.js`

Реализует поведение аккаунт-ассистента, черновики ответов и режим утверждения.

## Обработчики

### `src/handlers/text.js`

Обрабатывает текстовые сообщения и перенаправляет их в сервисы AI.

### `src/handlers/voice.js`

Обрабатывает голосовые сообщения, отправляет их на распознавание и генерирует ответы.

### `src/handlers/photo.js`

Обрабатывает фото и может использовать мультимодальные функции AI.

## Конфигурация

Все параметры загружаются из `.env` в `src/config.js`.

Обязательные переменные:
- `BOT_TOKEN` — токен Telegram-бота;
- `OPENROUTER_API_KEY` — ключ OpenRouter.

Дополнительные переменные:
- `PORT` — порт для Express-сервера;
- `MAX_AUDIO_BYTES` — лимит размера аудио;
- `OPENROUTER_MODEL`, `OPENROUTER_STT_MODEL`, `OPENROUTER_AUDIO_MODEL` — модели для AI и аудио;
- `OPENROUTER_TTS_MODEL`, `OPENROUTER_TTS_VOICE`, `OPENROUTER_TTS_VOICES` — настройки синтеза речи;
- `VOICE_REPLY_MODE` — режим голосовых ответов.

Конфигурация аккаунт-ассистента и bot-to-bot задаётся отдельными переменными.

## Сценарии работы

### Обычный бот

1. Запускается `npm start`.
2. `index.js` инициирует `src/bot.js`.
3. `src/bot.js` валидирует конфигурацию и создаёт Telegram-бота.
4. Регистрируются команды, меню и обработчики.
5. Стартует Express-сервер для здоровья приложения.

### Userbot

1. Запускается `npm run userbot`.
2. userbot подключается к Telegram через пользовательскую сессию.
3. Он прослушивает входящие сообщения и отвечает на `.ping` и `.say`.

### Генерация сессии

1. Запускается `npm run telegram:session`.
2. Пользователь проходит авторизацию в Telegram.
3. В консоль выводится `TELEGRAM_STRING_SESSION`.
4. Сессию сохраняют в `.env`.

## Взаимодействие компонентов

- `src/commands.js` — маршрутизирует команды и кнопки.
- `src/handlers/` — разбивает логику по типам входящих сообщений.
- `src/services/` — предоставляет API-интеграции и логику работы данных.
- `src/config.js` — гарантирует, что приложение стартует только с корректными переменными окружения.
